# Design documents

Planning material for a new tumour-metaprogram package aimed at *Nature Methods*.
Everything here is an AI-assisted draft from 2026-10-02. Citations carry verification tags;
re-check them, and run a manual bioRxiv / Google Scholar scoop search, before relying on them.

| File | Contents |
|---|---|
| [02_TESSERA_proposal.md](02_TESSERA_proposal.md) | **Start here.** The proposed method (TESSERA), package architecture, benchmark and validation plan, go/no-go pilots, timeline, risks and open decisions. |
| [01_landscape_and_gap_analysis.md](01_landscape_and_gap_analysis.md) | How the current Gavish/3CA pipeline fails, step by step; competitor table; unused statistical tools; ground-truth resources; publication bar; scoop risk; novelty gaps. |
| [03_design_panel.md](03_design_panel.md) | The four candidate concepts (CREDO, CALIPER, InvarMP, CERT-MP) and eight adversarial referee reports that shaped the proposal. |
| [04_literature_sweeps.md](04_literature_sweeps.md) | Raw output of the five literature sweeps (117 items). |
| [05_pilot_P1.md](05_pilot_P1.md) | How to run the P1 pilot audit (`mpaudit`), what each axis measures, the GO/NO-GO rule and caveats. |
| [referee_checks/](referee_checks/) | Toy simulations the referees ran, which the proposal relies on. |
